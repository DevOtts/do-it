["src/file-01.spec.js"]` and `gates.reuse.never_reuse: ["src/file-02.spec.js"]`, scope `push`, leg `unit`. Planted rows
are written with a valid `crc` (spine `canonicalJson`, `core/spine/src/hash.mjs:12`) and current keys unless stated.
