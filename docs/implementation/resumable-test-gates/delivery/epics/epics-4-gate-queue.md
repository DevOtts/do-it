Legend: G-n governance rule · T-EID-NN test case · Wn wave · Rn default · Dn ruling — see GLOSSARY.md

Shared test conventions for both epics:
- Every test spawns queue processes with `baseEnv(home)` (`core/spine/test/helpers.mjs:21-27`): HOME is a fresh temp
  dir, so the queue root is `{tmp}/.do-it/queue/` and the real machine queue is never touched.
- Memory state comes from `DO_IT_GATE_SIGNALS` (R19), a JSON fixture re-read every poll. Default fixture:
  `{"pressure":"normal","total_mb":10000,"avail_mb":9000,"swap_used_mb":0,"swapout_mb_per_s":0}` ⇒ budget 6000 MB at
  the default 60 %.
- Until V1 wires `case 'queue'` into `cli.mjs` (CONTRACT §5), processes are started through
  `core/spine/test/g3/driver.mjs`, which splits argv at `--` itself and calls the exported `gateQueueCmd`. After V1 merges,
  the same cases also pass through `node core/spine/do-it.mjs gate queue …`.
- Fixture commands are small `node -e` scripts or files under `core/spine/test/g3/fixtures/` that write marker files
  (`started`, `pids.json`, `order.txt`) in the test's temp dir.
