# Motion tooling for the README

Decision record for the animated README visuals (hero, pipeline, four use cases).

## What "Claude Motion" turned out to be

There is no single official product by that name. Candidates read before choosing (source and SKILL.md read, nothing piped to a shell):

| Candidate | What it is | Fit for a GitHub README |
|---|---|---|
| [claude-gif](https://github.com/AgriciDaniel/claude-gif) (MIT, 28 stars, commit 7bb7e47) | Claude Code skill family: Remotion, Veo, FFmpeg and **animated SVG to GIF via Playwright + FFmpeg** (Mode D) | Best: covers the GIF/WebP fallback path and SVG capture; `install.sh` only copies skill folders (read first) |
| [Pixel2Motion](https://github.com/nolangz/pixel2motion) (MIT) | Raster logo to SVG, then JS-rendered HTML animation | No: output is standalone JS HTML; GitHub strips JS |
| [Remotion skills](https://github.com/remotion-dev/skills) | React to MP4/GIF video rendering | Heavy; raster video, not crisp vector, no license file |
| [HyperFrames](https://github.com/heygen-com/hyperframes) (Apache-2.0) | HTML to video for agents | Video output, large toolchain |

## What was chosen

1. **Primary output: hand-authored CSS-animated SVG**, generated by `scripts/gen-motion-assets.mjs`. GitHub renders animated SVG in `<img>` (CSS `@keyframes`, no script), it is tens of KB, crisp, and the dark card background is safe in light and dark themes.
2. **Installed tool: `claude-gif`**, for the animated GIF/WebP fallback if a surface ever cannot render SVG animation (`/gif convert`, Mode D: SVG to GIF through Playwright and FFmpeg).

Installed at: `~/.claude/skills/claude-gif`, `claude-gif-create`, `claude-gif-generate`, `claude-gif-convert`, `claude-gif-optimize`, `claude-gif-edit` (user level).

```bash
git clone --depth 1 https://github.com/AgriciDaniel/claude-gif.git
# read install.sh and the SKILL.md files, then:
bash claude-gif/install.sh        # copies skills/* into ~/.claude/skills, creates ~/Documents/gif_output
# optional, only when a GIF is needed: /gif setup   (installs gifsicle; ffmpeg is already present)
```

## Reduced motion

Every element's default style is its final state. The animated files add `@media (prefers-reduced-motion:reduce){*{animation:none!important}.pk{display:none}}`, so a viewer who asks for less motion sees the finished frame. Each use case also has a `-static.svg` twin with no animation at all, and the original hero and pipeline are kept as `do-it-hero-static.svg` and `do-it-pipeline-static.svg` (they are the source the generator animates).

## Regenerating

```bash
node scripts/gen-motion-assets.mjs            # rewrites the animated files
node scripts/gen-motion-assets.mjs --check    # fails when a file is stale (tests/readme/motion.test.mjs)
```

Edit timings and copy in the generator, never in the generated SVGs. Verification log: `.taskstate/results/readme-motion.md`.
